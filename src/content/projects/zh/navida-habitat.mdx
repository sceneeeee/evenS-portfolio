<span className="eyebrow">01 / 概述</span>

## 工程接口完成，不等于导航成功。

项目连接模型端策略服务与 Habitat 执行端。当前真实 Habitat 视频使用 **Deterministic Fake Policy**，只验证 HTTP、动作队列和仿真环境执行；视频中没有运行 NaVIDA checkpoint。

<div className="callout"><strong>完成范围</strong><p>软件集成已完成；没有正式 VLN 基准、学习式导航成功或实体机器人部署。</p></div>

<section id="problem" className="case-section">
<span className="eyebrow">02 / 问题与动机</span>

## 让模型文本成为有界、可审计的仿真动作。

视觉语言导航模型输出动作文本，而 Habitat 以原子动作推进。桥接需要 episode 身份、RGB 帧、步序校验、严格解析和决策跟踪。HTTP 服务区分模型一次决策与之后排队执行的多个环境步。
</section>

<section id="architecture" className="case-section case-section-wide">
<span className="eyebrow">04 / 系统架构</span>

## 区分 HTTP 决策与仿真执行步。

评估端发送当前 RGB、自然语言指令和 step 信息，模型侧返回由队列控制的原子动作，真实 Habitat `env.step()` 每次执行一步。在固定动作演示中由确定性假策略替代模型，但 HTTP 和仿真执行都是真实的。

<section id="implementation" className="case-section">
<span className="eyebrow">05 / 技术实现</span>

- Habitat 0.3.3 的 skokloster-castle 场景、reset、RGB 渲染均已验证。
- 前进一步约 **0.249999864 m**；单次左右转约 **±15°**，连续左转约 **30°**；显式 STOP 结束回合。
- Stage C 正常路径有 **4 次 HTTP 请求 / 4 次真实 Env step**。
- 无效输出路径有 **3 次请求 / 仅 2 次真实 Env step**，没有隐藏 fallback。

历史真实 checkpoint 曾在 RTX 4060 Ti 8 GiB 上做 4-bit 推理，但**不是这段工程视频的策略**。
</section>

<section id="results" className="case-section case-section-wide">
<span className="eyebrow">06 / 实验结果</span>

## 工程链路通过；学习式导航任务并未通过。

| 证据 | 记录数值 | 边界 |
|---|---|---|
| 确定性 Habitat 工程展示 | **21 动作、21 HTTP 请求、11 固定决策** | 验证接口，不是 NaVIDA 推理 |
| 碰撞与终止 | **0 碰撞、显式 STOP** | 仅该脚本回合，不等于寻路成功 |
| 视频 | 640 × 480、21 帧、2 fps、10.5 秒 | 回放速度不是控制吞吐 |
| 回归测试 | 模型端 **98 passed / 1 skipped**；评估端 **56 passed** | CI 不运行完整 Habitat |
| 历史真实 NaVIDA 80 步 grounded run | success **0**、SPL **0**、最终距离约 **8.620 m** | 真实模型失败；Oracle 单独对照成功 |

早期真实模型五步 HTTP 冒烟中的语言指令与随机 PointNav 目标不匹配，因此只证明连接。历史有目标约束的 80 步真实模型实验**失败**；并非正式 R2R/RxR 基准。
</section>

<section id="failure-analysis" className="case-section">
<span className="eyebrow">07 / 失败分析</span>

## 接口正确不等于模型有效。

遇到不合法模型动作文本时，评估端不会悄悄使用 `move_forward` 等替代动作，因此 HTTP 请求数可以高于真实环境步数。真实模型历史 80 步停止位置错误，不能把单独的 Oracle 对照结果记作 NaVIDA 成功。
</section>

<section id="limitations" className="case-section">
<span className="eyebrow">08 / 局限性</span>

没有正式 VLN benchmark、多场景泛化测试、实体机器人部署或生产级 HTTP 服务加固。本次视频为固定动作 Fake Policy，不能视为自主导航；原始授权 Habitat 数据集和模型权重并未通过作品集发布。
</section>
